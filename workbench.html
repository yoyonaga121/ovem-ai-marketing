ARCHITECTURE / 06

三层结构，壳只做编排

入口层只编排与呈现；运行时层只执行与记账；数据层只做契约与持久化。运行时零 DOM 依赖，方案 B 可直接复用。

L1入口层 · workbench.html

6 组导航、Mission 队列、Plan / Trace / Artifacts / 成本卡；不写业务数据，只读 store、发事件。

L2运行时层 · runtime/*.js

trace / store / tools / executor / selftest，零 DOM 依赖；7 步 9 调用、七态白名单、成本单一入口。

L3数据层 · data/*.js + IndexedDB

配置进 git（schema + 快照）；运行态进 `ovem-os-v3`，6 store / 18 索引，不进 git。
